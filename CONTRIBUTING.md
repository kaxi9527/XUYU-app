# 参与贡献 · Contributing

欢迎通过 Issue 反馈问题、讨论想法或提交 Pull Request。请先说明系统、芯片、复现步骤和预期结果；不要上传个人文件、AI 会话、令牌或其他私密信息。涉及文件移动、恢复、授权或模型调用的改动，请提供相应测试和限制说明。

Issues and pull requests are welcome. Include the operating system, processor architecture, steps to reproduce, and expected behavior. Do not upload personal files, AI conversations, tokens, or other private data. Changes involving file moves, recovery, permissions, or model calls should include relevant tests and known limitations.

请从当前主分支建立分支，在本地运行受影响模块的测试，在 PR 中说明变更与验证结果。维护者审阅后合并。

Create a branch from the current default branch, run tests for affected modules, and describe the change and validation in the PR. Maintainers review contributions before merging.
